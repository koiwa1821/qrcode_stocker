保存とプライバシー

未登録の記録はこのブラウザのIndexedDBとサーバーに同期されます。登録後はアカウントのサーバーへ保存します。保存・同期の状態は各記録に表示されます。

削除と上限整理は論理削除です。通常の一覧や検索からは隠れますが、現時点でサーバーから物理削除しません。ページ読み込み時に取得したグローバルIPアドレスはこのブラウザのIndexedDBに保存します。
